# ARTI308 – Lab 8: K-Nearest Neighbors (KNN)

## Overview
This lab focuses on using the K-Nearest Neighbors (KNN) algorithm for classification tasks.  
The project applies KNN to classify data from the provided dataset and evaluates the model performance using different metrics.

## Dataset
The dataset used in this lab is:

`KNN_Project_Data.csv`

The dataset contains features used to train and test the KNN classification model.

## Objectives
- Load and explore the dataset
- Preprocess the data before training
- Apply feature scaling using StandardScaler
- Split the data into training and testing sets
- Train a KNN classification model
- Evaluate the model using performance metrics
- Tune the K value to improve model performance

## Steps Performed
- Data loading and exploration
- Feature scaling using StandardScaler
- Train-test split
- Model training using KNN
- Model evaluation using confusion matrix and classification report
- Hyperparameter tuning to find the optimal K value

## Tools and Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Model Used
- K-Nearest Neighbors Classifier

## Results
The KNN model was successfully trained and evaluated.  
Different K values were tested, and the optimal K value was selected based on the error rate.

## Conclusion
The KNN algorithm was able to classify the dataset successfully after applying feature scaling.  
Choosing the best K value helped improve the model performance and reduce classification errors.
