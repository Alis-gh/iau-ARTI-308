# ARTI308 – Lab 7: Logistic Regression

## Overview
This lab focuses on using Logistic Regression to predict whether a user will click on an advertisement.  
The project analyzes demographic and online behavior data to build a classification model and evaluate its performance.

## Dataset
The dataset used in this lab is:

`advertising.csv`

The dataset contains user information such as demographic details and online behavior features that help predict ad click activity.

## Objectives
- Explore and understand the dataset
- Visualize important data patterns
- Select relevant features for prediction
- Split the data into training and testing sets
- Train a Logistic Regression model
- Evaluate the model using classification metrics

## Steps Performed
- Data exploration and visualization
- Feature selection
- Train-test split
- Model training using Logistic Regression
- Model evaluation using performance metrics

## Tools and Libraries
- Python
- Pandas
- Seaborn
- Matplotlib
- Scikit-learn

## Model Used
- Logistic Regression

## Results
The Logistic Regression model was successfully trained and evaluated.  
The model showed good performance in predicting whether users clicked on advertisements based on the given features.

## Conclusion
Logistic Regression was effective for this classification task.  
The model was able to identify patterns in user behavior and demographic data to predict advertisement clicks with good performance.
