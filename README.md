# ARTI308 – Machine Learning Labs

This repository contains the lab work for the **ARTI308 – Machine Learning** course.  
Each lab focuses on a different machine learning concept, starting from basic GitHub setup and dataset exploration to classification, regression, clustering, and model evaluation techniques.

## Owner
Ali Alghadeer

## Note
Each lab is organized in a separate GitHub branch.

---

## Labs Summary

| Lab | Topic | Description |
|---|---|---|
| Lab 1 | GitHub Setup | Created a GitHub account and set up a repository with a README file. |
| Lab 2 | Dataset Selection | Selected the Steam Games dataset and defined a classification problem based on Metacritic score. |
| Lab 3 | Exploratory Data Analysis (EDA) | Explored the Steam Games dataset by checking missing values, duplicates, statistics, distributions, and correlations. |
| Lab 4 | Data Quality & Preprocessing | Applied data cleaning, type conversion, missing value handling, outlier detection, normalization, and PCA. |
| Lab 5 | Feature Engineering | Created new features, tested categorical reduction, and applied feature selection while maintaining good accuracy. |
| Lab 6 | Linear Regression | Built a Linear Regression model to predict yearly customer spending using the Ecommerce Customers dataset. |
| Lab 7 | Logistic Regression | Used Logistic Regression to predict whether a user clicks on an advertisement. |
| Lab 8 | K-Nearest Neighbors (KNN) | Applied KNN classification, feature scaling, model evaluation, and tuning the best K value. |
| Lab 9 | Decision Trees & Random Forest | Compared Decision Tree and Random Forest models for predicting loan repayment status. |
| Lab 10 | Support Vector Machines (SVM) | Used SVM to classify Iris flower species and applied hyperparameter tuning using GridSearchCV. |
| Lab 11 | K-Means Clustering | Applied K-Means clustering to segment credit card customers based on spending and financial behavior. |
